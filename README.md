# Java Roadmap

PWA-трекер подготовки к стажировке Java Backend. Этапы роадмапа, практика LeetCode по темам, ачивки, заметки, чек-лист минимума и синхронизация через приватный GitHub Gist. Прогресс живёт в пиксельном лагере: костёр растёт со стриком, а дом достраивается по мере закрытия тем.

**Рабочее приложение:** https://kezarych.github.io/Java-Roadmap/

## Что внутри

- 6 этапов: от Java Core и коллекций до Spring Boot, Docker, CI и поиска стажировки в Беларуси.
- 63 задачи с пояснениями — не просто список тем.
- Чек-лист минимума к собеседованию.
- Заметки к каждому этапу с автосохранением.
- Практика LeetCode по 15 темам: от массивов до динамики и многопоточности.
- Статистика LeetCode по нику: всего решено, Easy / Medium / Hard, рейтинг.
- Кнопка «Дай мне задачу» — случайная нерешённая задача с темой и уровнем.
- 22 ачивки за прогресс, серию, практику и синхронизацию.
- Серия занятий и мини-календарь активности за 14 дней.
- Карта-лагерь: костёр, шесть узлов этапов, тропы находок, лиса-компаньон и маяк «Стажировка».
- Дом из шести стадий: фундамент → стены → крыша → дверь → окна → труба.
- Ресурсы за прогресс: камень и искры; заморозки пропущенных дней.
- Календарь огня в стиле GitHub: любой прошедший день можно зажечь или отжечь.
- Находки за серию: вода, ковёр, светлячки, кристалл, флюгер и другие косметические эффекты.
- Тёмная пиксельная тема лагеря и читаемая типографика: Exo 2 для интерфейса, JetBrains Mono для чисел и подписей.
- Экспорт и импорт JSON без токена и интернета.
- Синхронизация через GitHub Gist с разрешением конфликтов по `updatedAt`.
- Офлайн-режим через service worker.
- Только HTML, CSS и JavaScript. Без сборщиков и библиотек.

## Карта и лагерь

Карта — основной экран. На ней только игровые объекты, без ярлыков разделов:

- костёр: клик открывает календарь огня; кнопка «История огня» в HUD делает то же;
- дом: клик переключает на вкладку «Дом»;
- шесть узлов этапов: клик открывает шторку с задачами;
- тропы находок по краям, лиса-компаньон и финальный маяк «Стажировка».

На десктопе вкладки «Карта / Дом» находятся в шапке. На мобильных снизу фиксированная плашка, а карта не сжимается: она шире экрана и прокручивается вбок с подсказкой «листай вбок».

## Дом

Дом достраивается по проценту закрытых тем роадмапа:

```text
Фундамент → Стены → Крыша → Дверь → Окна → Труба
```

Пока дом не достроен, вокруг видна пунктирная строительная площадка. При срыве серии ничего не отнимается — дом растёт только вверх. Вкладка «Дом» показывает большую сцену дома, стадию, прогресс, ресурсы, комнаты практики, ачивок, чек-листа и настроек, а также сундук находок.

Ресурсы начисляются один раз за каждую новую отметку (`state.rewarded`):

- `stone` — за первую отметку темы роадмапа;
- `ember` — за первую решённую задачу практики;
- «Задача дня» даёт +1 к камню и искрам.

## Серия, заморозки и находки

- Стадии огня: 0 / 3 / 7 / 14 / 30 / 60 / 100 дней — от тлеющих углей до рассвета.
- Если сегодня не отмечено, огонь гаснет ступенчато, но не блокирует приложение.
- Ручное «Зажечь» доступно раз в день без штрафов.
- Клик по костру открывает календарь на 365 дней: видны зажжённые, пустые и замороженные дни; любой прошедший день можно зажечь или отжечь. Ручное отжежение подавляет автозаморозку этого дня и записывается в `state.manualOff`.
- Каждые 7 уникальных наград дают заморозку (максимум 3). Заморозка закрывает пропущенный вчерашний день и сохраняет серию; при запуске она применяется автоматически, если пропущен ровно один день.
- Тропы открываются на стрике 3 / 7 / 14 / 21 / 30 / 45 / 60 / 100 дней и выдают одноразовую находку с косметическим эффектом (синее пламя, ковёр у дома, светлячки, кристалл, флюгер и т.д.).
- После 100 дней включается рассвет, затем каждые 50 дней добавляется звезда; звёзды не сгорают и хранятся в `state.stars`.

## Связь с Android-приложением

`roadmap.json` — единый источник контента. Сайт при старте загружает его и обновляет экран, а при отсутствии сети использует встроенную копию. Android-приложение при старте пытается загрузить:

```text
https://kezarych.github.io/Java-Roadmap/roadmap.json
```

Если сети нет или сервер недоступен, приложение берёт встроенную копию из `app/src/main/assets/roadmap.json`. Поэтому достаточно обновить `roadmap.json` на сайте — приложение подтянет новый план при следующем запуске.

Прогресс в мобильном приложении хранится локально в Room. Синхронизация прогресса между сайтом и Android через общий Gist пока не включена: на сайте она уже работает, для приложения это отдельный шаг.

## Синхронизация между устройствами

1. Создайте fine-grained GitHub-токен с правом **Gists: Read and write**.
2. Откройте «Дом» → «Настройки» (или `#settings`).
3. Вставьте токен. ID Gist можно оставить пустым — будет создан новый приватный Gist с файлом `roadmap.json`.
4. На втором устройстве вставьте тот же токен и ID Gist.

Токен и ID хранятся только в `localStorage` браузера и не попадают в экспорт, Gist или репозиторий.

## Данные

Всё состояние хранится одним объектом `version: 4` в `localStorage` под ключом `go-roadmap-v1` (ключ оставлен для совместимости со старой версией сайта). Конфигурация синхронизации — под ключом `go-roadmap-sync-v1`.

Кроме задач, практики, ачивок, заметок, серии, статистики LeetCode и чек-листа, состояние содержит:

- `resources` — камень и искры;
- `rewarded` — выданные награды за темы и задачи;
- `finds` — найденные предметы и даты;
- `frozen` и `spentFreezes` — заморозки;
- `manualOff` — дни, которые пользователь сознательно погасил;
- `stars` — накопленные звёзды;
- `celebrated` — отметки о разовых анимациях пристроек.

`activity`, `frozen` и `manualOff` хранятся до 400 дней. Старые состояния v2/v3 нормализуются в `normalizeState`: `wood`, `boost`, `manualDays` и `manualStack` отбрасываются, недостающие поля заполняются значениями по умолчанию. Экспорт и Gist сериализуют состояние целиком, поэтому новые поля переносятся автоматически.

## Обновление роадмапа

1. Отредактируйте `roadmap.json` (или скрипт сборки, если он есть).
2. Проверьте, что структура сохраняет поля `stages[].steps[]` и `stages[].tips[]`.
3. Обновите `CACHE_NAME` в `sw.js`, чтобы браузеры и PWA получили новую версию.
4. Закоммитьте и запушьте изменения.
